**SwiftAgents Core** is the Flutter package that brings the SwiftAgent AI support
agent into your Android and iOS app. You initialize it once with your company
credentials, create a context for each user, then render `SwiftAgentsView` either
as a bottom sheet or as an ordinary widget inside your own layout.

The package ships as `swift_agents_core` and pulls in everything the chat needs,
including image and file attachment support, so there is no separate UI package
to wire up.

## How it works

<Steps>
  <Step title="Initialize the SDK">
    Call `SwiftAgentsCore.init()` in `main()` with your **Company ID** and
    **API key**. This runs once for the lifetime of the app.
  </Step>
  <Step title="Get a context for the user">
    `SwiftAgentsCore.getContext(email: ...)` returns the conversation context for
    that user, creating it on first call and reusing it afterwards.
  </Step>
  <Step title="Show the view">
    Pass the context to `SwiftAgentsView`, then either call `.show(context)` to
    present it as a bottom sheet or place the widget directly in your tree.
  </Step>
</Steps>

<Note>
  You need both a **Company ID** and an **API key** before the SDK will connect.
  [Sign up](https://swiftagents.org/en/signup), then copy both from
  [Settings → API keys](https://swiftagents.org/en/dashboard/settings/api-keys).
</Note>

The SDK is a single Flutter package, `swift_agents_core`. It bundles the chat UI
and its dependencies, so there is nothing to configure in your build beyond the
platform permissions.

## Add the dependency

<CodeGroup>
```bash Flutter CLI
flutter pub add swift_agents_core
```

```yaml pubspec.yaml
dependencies:
  flutter:
    sdk: flutter
  swift_agents_core: ^<latest>
```
</CodeGroup>

<Tip>
  Prefer `flutter pub add`. It resolves the latest published version and writes
  the correct constraint into `pubspec.yaml` for you.
</Tip>

Then fetch packages:

```bash
flutter pub get
```

## Import it

A single import exposes everything: `SwiftAgentsCore`, `SwiftAgentsView`, and
`SwiftAgentsThemeData`.

```dart
import 'package:swift_agents_core/swift_agents_core.dart';
```

## Configure platform permissions

The SDK uses `image_picker` and `file_picker` so users can attach photos and
files to a conversation. Both platforms need permission entries before those
pickers work:

- **Android** — camera, network, and media permissions in
  `android/app/src/main/AndroidManifest.xml`
- **iOS** — camera and photo library usage descriptions in
  `ios/Runner/Info.plist`

<Warning>
  Skipping this step doesn't break the build. It fails at runtime, when a user
  taps the attachment button and the picker never opens, or iOS terminates the
  app for a missing usage description.
</Warning>

<Card title="Permissions setup" icon="lock" href="/sdk/permissions">
  The exact entries to paste into each platform's config.
</Card>

## Verify the install

Add the initialization call to `main()` and run the app. If your credentials are
wrong or missing, the chat surface won't load.

```dart
await SwiftAgentsCore.init(
  companyId: 'your_company_id',
  apiKey: 'your_api_key',
);
```

<Note>
  Copy both values from
  [Settings → API keys](https://swiftagents.org/en/dashboard/settings/api-keys)
  in your dashboard.
</Note>
